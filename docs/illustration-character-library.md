# SWOTBee character continuity guide

Use the same five people across SWOTBee illustrations: Nia, Ravi, Mei, Alex and
Helen. Preserve each person's face, apparent age, complexion, hair, build and
outfit while changing their action and props to explain the scene.

The priority is a coherent illustration family and people the audience can
identify with. Leadership characters do not need to look very old or use a
separate, realistic portrait style. Ravi and Helen can support leadership scenes,
and all five can appear in consulting, management and RevOps stories. Scene
context establishes their roles. All names are provisional internal labels.

## Use the shared illustration style

Follow the existing [material palette](../public/assets/illustrations/renewals/character-reference.json)
and [site color guidance](content-guidelines/homepage-color-system.md).

| Shared material | Main colors |
| --- | --- |
| Deliberate dark outline | `#20343B` |
| Blue clothing and props | `#1871A8`, shadow `#10577F`, highlight `#2F89B4` |
| Aqua clothing and props | `#247F76`, shadow `#195F59`, highlight `#76CABB` |
| Pale document accents | `#9FD3C7` |
| Mint clothing | `#D7EFDF`, light `#ECF8EE`, shade `#B3D7C2` |
| Small coral accents | `#FFA68E`, shading `#F67B5B` |
| Paper and cool neutral shadows | `#FFFFFF`, `#E8EBED` |
| Small natural gold details | `#E9BA4D` |

These are target colors for shared props and accents, and for clothing that
already uses those materials. Individual wardrobes can use additional colors:
Ravi's mauve/slate-grey and Helen's taupe/white/slate-blue follow the approved wardrobe lineup. Preserve each character's own natural skin and
hair from their identity image. The Nia JSON's skin and hair entries describe Nia;
they must not recolor the rest of the cast. New characters' exact complexion
swatches have not been independently defined as hex values.

Use smooth curves, controlled outlines and two or three intentional shades per
material. Keep the background transparent, with a small ground shadow where
helpful. White page canvas, white paper and cool neutral shading belong to this
family. Avoid cream paper, a yellow or sepia wash, heavy texture, glossy rendering,
fog and glow halos. Keep chart labels, text and claims in HTML.

## Create a new scene with continuity

1. Select character IDs from the library and attach each current identity image.
   For Ravi and Helen, also attach the approved wardrobe lineup and label it
   authoritative for clothing colors. Older pose-master fabric colors are historical.
   Use an additional approved scene only when useful, labelled **style only**.
   People in that extra scene are not automatically part of the requested cast.
2. Fill the [scene brief](illustration-scene-brief.txt): one message, each person's
   action, roles, minimum props, expression, gaze, composition and page location.
   Paste the selected characters' immutable traits and relevant continuity notes.
3. Generate or draw a new pose while preserving identity. Start from the current
   master references each time; using only the last generated scene can compound
   identity drift.
4. Review the face, apparent age, hair silhouette, complexion, build, outfit and
   accessories against those masters. Check hands, feet, prop connections and
   transparent edges at normal and enlarged sizes, on white and contrasting
   backgrounds.
5. Follow the requested review sequence. The consulting-page illustration refresh
   is being reviewed one image at a time. A selected character reference does not
   approve every future scene or authorize replacing all illustrations at once.
6. For approved website artwork, prepare native SVG paths and shapes with a
   viewBox. An embedded PNG is still raster. Do not include bitmap links,
   embedded images or `foreignObject` content. See the Nia guide for finishing.
7. Save a new versioned asset, wire it into its intended page with dimensions and
   suitable alt text, and run the validation in [development.md](development.md).

Examples of scene briefs:

- **Helen and Mei:** Helen reviews a concise renewal forecast while Mei indicates
  an exception requiring a decision. Use one report and one exception card. The
  message is that leadership receives a clear decision, supported by operational
  detail.
- **Ravi and Nia:** Ravi and Nia agree a renewal-process priority beside three
  connected workflow cards. The message is that business priorities guide the
  implementation.
- **Alex:** Alex compares an incoming record with a validated outgoing record.
  The message is that integration checks catch incomplete handoffs.

These examples are creative briefs, not client screenshots or claims of results.
Different actions and meaningful props should carry each story; avoid repeating
the reference notebook pose for every topic.

## Preserve and version the references

Use names such as `helen-forecast-review-v1.png` or
`ravi-nia-renewal-priorities-v1.svg`. Keep identity-master names separate from
scene names. When changing an identity, create a new master version, preserve the
old file and update the current pointer and revision notes in the library JSON.
Update this guide if a defining trait changes.

The curated PNGs, white previews and original generation prompts are retained in
`print-references/characters/`. Keep those selected reference files alongside the
handbook in version control when committing the work. They are reusable source
references, not disposable build output. Do not delete or overwrite them during
cleanup or make live pages depend on a generator's private output directory.

The `character-references-v1.json` and `character-references-v2.json` files in that
folder are historical snapshots. Earlier lineups and senior pairs include retired
Arun or Helen's superseded hair and clothes. Use this guide and the current library
JSON to select files instead of inferring currentness from those sheets.

The original character prompts reproduce the identity concepts, including their
initial poses. For a new action, use the scene brief with the current identity
image. Helen's v1 generation prompt describes superseded hair; her v2 revision
prompt records the pulled-back hairstyle and v3 records her plum-and-charcoal
wardrobe. Ravi's v1 prompt records the fresh independent character, using only
Alex, Mei and Nia as style references.

Ravi's v1/v2 full-body attempts were not selected. The user subsequently liked the
chest-up study, which records a coherent face, neck, shoulders, expression and
navy shirt. Its prompt and unchanged Helen comparison are retained separately.
Ravi's v3 prompt extends that selected study into a full figure. His v4 prompt
requests a small head-size reduction while preserving facial identity and the
body. Use the study to lock facial features, and the selected full-body reference for
head scale and composition. Do not return to the old sweater or pasted-on age cues.

Helen's v4 prompt removes all grey/white temple strands while preserving her
hairstyle, face, expression, body and plum-and-charcoal outfit.
