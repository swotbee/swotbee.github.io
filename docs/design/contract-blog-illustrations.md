# Contract blog illustration refresh

Created with the built-in ImageGen tool, using `public/assets/brand/logo-lockup.png` as the brand reference. Article PNGs are the rendered assets; legacy SVG URLs contain embedded raster scenes for compatibility. Tracked `-hero-share.png` files use a 1200 by 630 canvas containing the complete illustration and are selected with the optional `socialImage` frontmatter field. The export also refreshes the generated `.social.png` compatibility files.

Export originals using `node scripts/illustrations/export-contract-blog-heroes.mjs` followed by the three source PNG paths in line-item, amendment, responsibilities order. Originals remain in the generating session's ImageGen output directory.

The two workflow SVGs use editable text and the authentic embedded logo. Numbers and record IDs come from the articles. These are illustrative examples, not product screenshots or evidence of live integration behaviour.
